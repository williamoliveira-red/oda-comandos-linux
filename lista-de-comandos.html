Comandos do Linux

Lista de comandos

Aqui em baixo está alguns dos comandos mais usados no Linux separados por categoria na seguinte ordem:

  • Comandos de Gestão de Arquivos e Diretoria
  • Comando de Exibição ou Impressão de Arquivos
  • Comandos de Rede
  • Comandos de Edição de Texto
  • Comandos de Ajuda e Documentação
Comandos de Gestão descrição
ls Lista os arquivos do diretório
cd Acessa uma determinada pasta
pwd Mostra o caminho do diretório atual
locate Procura um arquivo e exibe seu caminho
mkdir Cria diretórios
mv Move ou renomea arquivos e diretórios
cp Copia arquivos e diretório
touch Cria um novo arquivo vazio
rm Remove um arquivo (rmdir para remover diretórios)
grep Procura em um arquivo partes com palavras específicas
Comandos de Exibição descrição
cat> Mostra o conteúdo do arquivo
head Mostra as primeiras linhas de um arquivo de texto
tail Mostra as últimas linhas de um arquivo de texto
less Mostra o conteúdo de um arquivo uma página por vez
Comandos de Redes descrição
hostname Exibe o nome da máquina na rede
ip Mostra as informações da interface de rede
ping Verifica conexão e tempo de resposta
Demais Comandos descrição
nano Editor de arquivo de texto (comando de edição)
find Procura o arquivo (comando de ajuda)
man Manual completo (comando de ajuda)
