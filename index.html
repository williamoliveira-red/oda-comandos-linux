Comandos do Linux

Uma rápida introdução ao Linux

O Linux é um sistema operacional de código aberto (open-source) e gratuito, baseado no Unix, que gerencia recursos de hardware através de um núcleo (kernel). É amplamente utilizado em servidores, supercomputadores, dispositivos móveis (Android) e computadores de mesa, sendo valorizado pela sua estabilidade, segurança e flexibilidade, permitindo modificações e distribuições personalizadas

Interação do usuário com o sistema operacional

O usuário interage com o sistema operacional através do programa Shell que recebe os comandos digitados pelo usuário os repassa ao SO para execução.
Também é possível interagir através de interfaces visuais (GUI);
